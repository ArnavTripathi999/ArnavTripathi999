<h3 align="center">I'm a 3D Artist, Animator & Unity Developer, and Co-Founder of NoteX Studios.</h3>

I'm based in **Delhi NCR, India**, where I co-founded **[NoteX Studios](https://www.notexstudios.in)**, an indie studio that makes story-driven games and game assets.

Our current title is **[Phantom Echoes: Chapter I](https://store.steampowered.com/app/4607190/Phantom_Echoes_Chapter_I/)**, a first-person psychological horror game billed as *India's first multiverse horror title*. A flight to Delhi goes wrong, and you wake up in a decaying hotel deep in a forest, solving puzzles and escaping entities while working out what's real.

At the studio we also run **[Asset on Demand](https://www.notexstudios.in/blank-1)** (custom Unity-ready 3D assets, from low-poly props to high-poly environments) and **[Game on Demand](https://www.notexstudios.in/god)** (we turn your game idea into a playable game you fully own).

When I'm not modelling, animating or wiring things up in Unity, I'm probably gaming. 🎮
